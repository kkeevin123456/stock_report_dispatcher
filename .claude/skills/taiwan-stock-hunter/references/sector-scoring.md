# 族群強度打分詳細標準

## 打分系統說明

總分 20 分，選 ≥ 12 分的族群進入 Phase 2。
若多個族群得分相近（差距 < 2 分），優先選「股價 vs 消息落差」得分高的。

## 各維度詳細評分標準

### 維度 1：新催化劑新鮮度（0~4 分）
| 分數 | 判斷標準 |
|------|---------|
| 4 | 近 2 週內出現全新結構性事件 |
| 3 | 近 2~4 週：法說會上調展望、外資評級升級 |
| 2 | 近 1 個月：業績優於預期、月營收創新高 |
| 1 | 1~2 個月前的舊消息持續發酵 |
| 0 | 純粹舊題材、找不到新催化劑 |

### 維度 2：法人態度轉變（0~4 分）
| 分數 | 判斷標準 |
|------|---------|
| 4 | 多家外資同步上調評級 + 大幅調升目標價（>20%） |
| 3 | 1~2 家外資評級升級，或多家調升目標價 |
| 2 | 投信連買 + 法人報告開始提及此族群 |
| 1 | 僅有分析師維持原評級但語氣轉正面 |
| 0 | 無法人報告、法人賣超、評級下調 |

### 維度 3：外資籌碼動向（0~4 分）
| 分數 | 判斷標準 |
|------|---------|
| 4 | 外資連續買超 ≥ 5 個交易日，且族群內多檔同步 |
| 3 | 外資連續買超 3~4 天，或單日大量買超（>5,000 張） |
| 2 | 外資零星買超，或從賣超轉持平 |
| 1 | 外資小幅賣超 |
| 0 | 外資大量賣超 |

### 維度 4：股價 vs 消息落差（0~4 分）—— 最重要
| 分數 | 判斷標準 |
|------|---------|
| 4 | 族群股價近 1 個月橫盤或微跌，但消息面/財報明顯改善 |
| 3 | 族群股價小漲（< 15%），消息面改善程度超過漲幅 |
| 2 | 族群股價已漲 15~25%，消息面部分反映 |
| 1 | 族群股價已漲 25~40%，大部分利多已反映 |
| 0 | 族群股價近 1 個月已漲 > 40% |

### 維度 5：基本面支撐（0~4 分）
| 分數 | 判斷標準 |
|------|---------|
| 4 | 三率三升 + 合約負債季增 + 月營收加速（全部符合） |
| 3 | 三率三升，或合約負債激增（QoQ > 20%） |
| 2 | 營收創新高但毛利率持平 |
| 1 | 有獲利但成長趨緩 |
| 0 | 連續虧損、EPS 年減、純題材無獲利支撐 |

## 特殊情況處理

### 情況 1：族群內個股分化嚴重
- 族群整體分數低，但其中 1 檔個股消息面異常強勁
- 處理：個股單獨進入 Phase 2，不帶整個族群

### 情況 2：找不到明確強勢族群（全部 < 12 分）
- 先輸出當前市場分析，說明市場處於什麼狀態
- 建議觀察清單，說明等待什麼訊號出現後再布局

### 情況 3：族群剛被媒體大篇幅報導
- 媒體報導 = 訊息已公開 = 股價大概率已反映
- 降低「新催化劑新鮮度」和「股價 vs 消息落差」的分數
